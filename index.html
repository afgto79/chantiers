Colle ici un token GitHub à portée réduite (fine-grained). Pour écrire le statut, il lui faut au minimum l'accès "Contents: Read and write" sur afgto79/chantiers. Pour afficher aussi le README des projets privés dans le panneau de détail, donne-lui en plus l'accès "Contents: Read" sur ces dépôts-là (ou choisis "All repositories" à la création). Sans cet accès élargi, seuls les dépôts publics affichent leur README. Le token est stocké seulement dans ce navigateur (localStorage) et n'est jamais envoyé ailleurs qu'à api.github.com.
