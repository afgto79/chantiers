# Captures d'écran

Convention simple : un fichier `<id-du-projet>.png` ici affiche automatiquement une
capture cliquable (agrandissable) dans le panneau de détail de ce projet sur la page.

L'`id` est celui utilisé dans `projects.json` (ex. `repartix.png` pour RepartiX,
`facture-explorer.png` pour facture-explorer). Pas de fichier pour un projet → la zone
capture reste simplement invisible, rien ne casse.
