# Captures d'écran

Convention simple : un fichier `<id-du-projet>.png` (ou `.jpg`, essayé en repli) ici
affiche automatiquement une capture cliquable (agrandissable) dans le panneau de
détail de ce projet sur la page.

L'`id` est celui utilisé dans `projects.json` (ex. `repartix.png` ou `repartix.jpg`
pour RepartiX). Pas de fichier pour un projet → la zone capture reste simplement
invisible, rien ne casse.
